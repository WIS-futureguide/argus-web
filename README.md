# Argus Web

Public Vue 3 admin dashboard for FutureGuide. This repository is `WIS-futureguide/argus-web` and uses the `master` branch. The dashboard uses the Argus admin API and Apollo authentication endpoints; existing hostnames and `VITE_*` settings remain unchanged.

Run `npm ci` to install dependencies, `npm run build` to build the app, and `npm run test:run` to run its tests.
